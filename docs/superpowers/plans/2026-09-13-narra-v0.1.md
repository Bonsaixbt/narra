# narra v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `narra` — a read-only, zero-config CLI + library + MCP server that clusters Pons v2 launches on Robinhood Chain into metas and answers `narra now`, `narra coin <CA>`, `narra flow`, `narra why`, `narra watch`.

**Architecture:** One Node process. `chain/` talks JSON-RPC through an own gate; `ingest/` fills a local SQLite cache from factory, curve and PoolManager logs; `analyze/` is pure functions (tokenize → cluster → heat → status → flow → verdict) over rows pulled from the cache; `cli/`, `mcp/`, `lib.ts` are thin presenters over one `Narra` facade.

**Tech Stack:** Node ≥ 22, TypeScript strict ESM, `viem` (ABI/transport only), `better-sqlite3`, `zod` v4 (schemas → JSON Schema), `@modelcontextprotocol/sdk`, `tsx` + `node:test` for tests.

**Spec:** `docs/OSS.md`

## Global Constraints

- Package `narrahood`, bin `narra`. MIT. Node ≥ 22.
- No code copied from other repos. Public chain facts only (addresses, event signatures, protocol params).
- Read-only: no private key, no signing, no `--live`.
- Every command has `--json`; streams have `--jsonl`; every JSON carries `schema_version`, `computed_at`, `window`, `head_block`, `lag_blocks`, `source`.
- Default RPCs: publicnode (`eth_call`, WSS), official Robinhood (`eth_getLogs`). No JSON-RPC batching. Concurrency 2 on public nodes.
- Cache at `~/.narra/narra.db`. Retention 48h raw trades.
- `IN` is membership, never a buy signal; no words "buy/signal/alpha" in output copy.
- Tests never touch the network.
